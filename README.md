## 🔧 Projetos & entregas

- **Ponte de mensageria conversacional** — API de WhatsApp integrada à plataforma de atendimento, templates aprovados, validação *fail-closed*, deploy via git worktree com rollback.
- **Cofre de segredos com injeção em memória** — credenciais cifradas com `age`, consumidas via systemd em tmpfs (0700), sem texto puro em disco.
- **Fila persistente multi-banco** — worker com estágio no PostgreSQL, pausa por arquivo e retomada por timer, túnel SSH restrito entre servidores.
- **Firewall automatizado e túneis privados** — iptables, listas de CDN, WireGuard e hardening de nginx.
- **Observação somente leitura e retenção LGPD** — snapshots, dry-run, quarentena; nada apagado sem decisão explícita.
- **Vault Obsidian multi-IA**, **pipeline de transcrição com Whisper** e o **próprio portfólio** (HTML/CSS puro, 6 cenas, i18n PT/EN/RU).
